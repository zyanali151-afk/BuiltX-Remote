# BuiltX Remote

Universal remote for Android TV, PC, and more.

Built by Zyan Ali / BuiltXStudios.

## Vision

One phone app controls:
- Android TV (Google TV protocol)
- Linux PC (custom companion)
- Windows PC (custom companion)
- macOS (custom companion)

## Status

🚧 Session 1: Scaffolding

## Tech Stack

- Kotlin (Android)
- Jetpack Compose (UI)
- TLS + Protocol Buffers (protocol)
- Python (companion servers)
